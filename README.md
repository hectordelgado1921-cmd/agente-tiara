# ⚓ Agente Tiara

Aplicación web del Agente Tiara con la base de datos de septiembre de 2026.

La base de datos se guarda como JSON compacto para evitar el límite de 25 MB del cargador web de GitHub. Los datos provienen del Excel de septiembre; se conserva la información de las celdas y se omite únicamente el contenido multimedia/formato de Excel que no necesita la aplicación.

## Archivos
- `app.py` — aplicación Streamlit.
- `requirements.txt` — dependencias.
- `base_conocimiento_tiara_septiembre_2026.json` — datos procesados del Excel de septiembre.

## Publicación
Preparado para Streamlit Community Cloud.
